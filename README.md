# Business Management Analyst Portfolio

**Anjali Yanumula** | [LinkedIn](https://www.linkedin.com/in/anjali-yanumula-1b4393325)

Two practice projects that show the skills used in a Business Management analyst role in a client service or private banking team: data analysis, executive reporting, risk and control support (RCSA), coordination and process improvement.

> **Data disclaimer:** All data in this repository is **synthetic (invented)**. Real bank data is confidential. The projects are meant to show method, structure and thinking, not real performance figures.

## Projects

| # | Project | Tools | What it shows |
|---|---------|-------|---------------|
| 1 | [Client Service Performance Dashboard](README_Project1_Client_Service_Dashboard.md) | Excel | Analysing 500 client requests against SLA targets and presenting results on a one-page executive dashboard |
| 2 | [RCSA and Process Improvement Pack](README_Project2_RCSA_Process_Pack.md) | Excel, PowerPoint | A mock Risk Control Self-Assessment, an action tracker, a process simplification proposal and a town hall agenda |

## Skills demonstrated

- Excel: INDEX/MATCH, COUNTIFS, AVERAGEIFS, IF logic, data validation, conditional formatting, native charts, assumption-driven models
- Dashboard and report design with a written design rationale
- Turning data into short, executive-ready recommendations
- Operational risk: inherent and residual risk scoring, control effectiveness, heatmaps, action tracking
- PowerPoint: concise decks for management and team sessions
- Process improvement thinking, with measurable pilot targets

## How to use

Download the files and open them in Excel or PowerPoint. In both workbooks, **blue text is an input** you can change and **black text is a formula**. Changing an input recalculates everything that depends on it.
